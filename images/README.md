# Photography drop-in

Place licensed product / category / hero photos in this folder and register them in `manifest.json`:

```json
{
  "hero": "hero-setup.jpg",
  "products": { "dualsense-white": ["dualsense-1.jpg", "dualsense-2.jpg"] },
  "categories": { "gaming-chairs": "cat-chairs.jpg" }
}
```

Listed images replace the generated renders automatically (product cards, product gallery, category tiles, hero).
Recommended: product shots on a neutral background, 1200×900 (4:3); hero 2400×1350 (16:9) with the subject on the right 60%.
